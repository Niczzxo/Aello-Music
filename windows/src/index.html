        About Aello

        Aello — Sound in Motion.

        Version 6.1.45 · Windows desktop (unsigned build).

        Developer: Niczzxo

        Aello is open-source software under the GPL-3.0 license, based on the open-source BeatWave and PulseWave projects. This Windows version is a fresh implementation for desktop; it is not affiliated with YouTube, Google, or any other streaming service.

        Cast is not available on Windows — there is no Cast SDK for this desktop stack. Also not available on this platform: Listen Together LAN mode, Android home-screen widgets, song recognition (Shazam), JioSaavn, desktop Wi-Fi Sync, DJ mixing, skip silence, ringtones, and always-on display. Everything else in this build — account sign-in, YouTube sync, downloads, synced lyrics, the equalizer, Listen Together, and the sleep timer — runs on the desktop.
