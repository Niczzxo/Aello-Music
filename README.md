## Features

- Background playback, downloads, and synced lyrics
- Parametric EQ and 8D spatial audio
- Listen Together (Aello Sync)
- Home feed, Library, and Search
- Widgets, Cast, and Android Auto
- Liquid Glass UI with theme colors

## Download

Get the latest APK from the
[releases page](https://github.com/Niczzxo/Aello-Music/releases/latest).

## Building

Open the project in Android Studio (JDK 21, Android SDK 37) and run the
`app` module, or build with Gradle:

```sh
./gradlew assembleDebug
```
